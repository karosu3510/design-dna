Design DNA · Inspiration kit

a.Record

A warm audio dashboard system. Cream canvas, white cards, one red accent for "live". Inter for words, Geist Mono for numbers. Built for vocal tracking, but the tokens carry into any calm, precise interface.

04 · Motion

Two easings, three durations. Real-time data uses low-pass smoothing (0.05–0.18), not CSS transitions.
// transitions
--ar-ease-out:  cubic-bezier(0.22, 0.61, 0.36, 1);  // entrances
--ar-ease-soft: cubic-bezier(0.4, 0, 0.2, 1);       // everything else
--ar-dur-fast: 120ms;
--ar-dur-base: 240ms;
--ar-dur-slow: 600ms;

// real-time numbers (don't use CSS)
value += (target - value) * 0.18;  // snappy   — input level
value += (target - value) * 0.05;  // inertial — LUFS, BPM

15 · For AI · Cursor / Claude rules

Paste this into .cursorrules or any LLM system prompt. It primes generation in a.Record style — no purple gradients, no display serifs, no rogue accent colors.
↗ Open ai-prompt.md 
Use the a.Record design system for all UI in this project.

- Background canvas is warm cream #eceae3, never pure white. Card surfaces are #ffffff.
- Inner panels (hero, sidebar, large blocks) use #f1efe9.
- All interactive surfaces are 999px pill radius. Cards use 30/20/16/14 radius scale.
- Inter for everything except numerical data. Geist Mono with tabular-nums for any number that ticks (timers, counters, dB, LUFS, BPM, file sizes).
- Headlines: letter-spacing -0.025em. Body: -0.005em. Uppercase labels: +0.18em at 10.5px Inter Medium.
- Exactly one accent: #f24a3a. Reserve it for live recording, errors, or destructive states. Never for branding, links, charts, decoration.
- No gradients. No saturated UI colors. No sharp/glow shadows.
- Three shadow recipes only: card, glass (with backdrop-filter blur 18px), pill.
- Spacing on a 4px grid. Motion: 240ms cubic-bezier(.22,.61,.36,1) for entrances; real-time numbers via low-pass smoothing 0.05–0.18.
- Reuse classes from design-system.css before authoring new CSS: .ar-shell, .ar-panel, .ar-pill, .ar-glass, .ar-mono, .ar-rec-dot, .ar-cap.

If a request requires a saturated color, sharp shadow, or display serif, push back — those break the system.

16 · For AI · Tailwind preset

Drop tailwind-tokens.js into a Tailwind project as a preset and you instantly get bg-canvas, text-ink, rounded-shell, shadow-card.
// tailwind.config.js
module.exports = {
  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

// then in your markup:
<div class="bg-canvas text-ink min-h-screen">
  <article class="bg-shell rounded-shell shadow-card p-7">
    <h1 class="text-h1">Vocal tracking</h1>
  </article>
</div>
