Vortex
Gallery.

A deep-space WebGL gallery system. Void canvas, vintage ember accent, momentum-driven scroll. Distilled from J0SUKE / vortex-gallery for cinematic media archives, photo essays, and label catalogs.

04 · Motion

Three easings, three durations. Wheel/momentum-driven values use lerp + RAF, never CSS transition.
// CSS transitions
--vg-ease-vortex: cubic-bezier(0.16, 1, 0.3, 1);     // hero entry, image flip-in
--vg-ease-soft:   cubic-bezier(0.4, 0, 0.2, 1);       // default UI
--vg-ease-snap:   cubic-bezier(0.22, 0.61, 0.36, 1);   // affordance
--vg-dur-fast: 120ms;
--vg-dur-base: 260ms;
--vg-dur-slow: 640ms;

// Lerp constants — wheel/cursor (use in RAF, not CSS)
current += (target - current) * 0.18;  // snappy   — cursor follow
current += (target - current) * 0.10;  // balanced — default scroll
current += (target - current) * 0.05;  // inertial — vortex camera

15 · GitHub 工程结构

这张卡片的视觉效果直接取自 J0SUKE 的开源项目 vortex-gallery，使用 Three.js + GLSL + 600 instanced mesh 实现。下面是源仓库的工程结构：
J0SUKE / vortex-gallery repo ↗ live demo ↗ 
vortex-gallery/
├── public/
│   └── frames/512/           // 20 张 512px 海报底图（atlas 拼接源）
│       ├── p1.jpg ... p13.jpg
│       └── 14.jpg ... 20.jpg
├── src/
│   ├── shaders/
│   │   ├── vertex.glsl           // 圆柱排列 + 旋转 + zPos wrap
│   │   ├── fragment.glsl         // atlas UV 采样
│   │   ├── center-vertex.glsl    // 中心 plane 同步切图
│   │   └── center-fragment.glsl
│   ├── main.ts                   // App 入口 + RAF loop
│   ├── canvas.ts                 // THREE 场景 / 相机 / wheel 输入
│   ├── gallery.ts                // ★ 核心：600 instancedMesh + atlas 拼接
│   └── style.css                 // 仅 reset + canvas 全屏
├── index.html                    // canvas#webgl + Vite entry
├── package.json                  // vite + three + gsap + normalize-wheel
└── vite.config.js                // vite-plugin-glsl
关键文件： src/gallery.ts 是整张卡的灵魂 —— 600 个 BoxGeometry 实例排成 30×20 的圆柱阵列，atlas texture 把 20 张图拼成单张大图避免 texture binding 切换；vertex.glsl 用 quaternion rotation 让每个 mesh 朝向圆心；canvas.ts 接 wheel 事件后用 lerp 0.05 把 scrollY 平滑成相机 momentum。

16 · For AI · Cursor / Claude rules

把这段粘进 .cursorrules 或任意 LLM 系统提示词。让生成默认走 Vortex Gallery 风格 —— 不会跑出渐变、亮色、双重色调。
↗ Open ai-prompt.md 
Use the Vortex Gallery design system for all UI in this project.

- Page canvas is #0a0a0a (void). Never lighter than #1f1f1f for any background. No off-white. No gradients to lighter colors.
- Surface depth scale: void #0a0a0a → depth #101010 → shell #161616 → soft #1f1f1f. Each tier is +6% black.
- One ember accent only: #ff7a3d. Reserve for active state, primary CTA, "live", current item. Don't add a second saturated red/pink/purple.
- Optional: sun #ffd24a for badges, ocean #3a78ff for links — only if the brief truly needs them.
- Inter Tight 500 for hero / display / h1 / h2. Letter-spacing -0.04em on hero, -0.02em on h1/h2.
- Inter for UI / body. Weights 400 / 500 only — never 700.
- JetBrains Mono with `font-variant-numeric: tabular-nums` for every ticking or grid-aligned number.
- Spacing: 4px grid (4/8/12/16/20/24/32/48/64). Never 5/7/10/15.
- Radius: 20 (shell) / 14 (panel) / 10 (card) / 6 (tile) / 999 (pill). Five values only.
- Don't use CSS transitions for wheel-driven values. Use lerp in requestAnimationFrame:
  current += (target - current) * 0.05;  // vortex camera (inertial)
  current += (target - current) * 0.10;  // default scroll
  current += (target - current) * 0.18;  // cursor follow (snappy)
- Easings: vortex cubic-bezier(0.16,1,0.3,1) / soft cubic-bezier(0.4,0,0.2,1).
- Reuse classes from design-system.css before authoring new CSS:
  .vg-shell .vg-panel .vg-tile .vg-pill .vg-pill--ember .vg-btn-ghost
  .vg-hero .vg-display .vg-h1 .vg-h2 .vg-body .vg-cap .vg-index .vg-mono
  .vg-poster .vg-dot .vg-rule

If a request requires a light background, two saturated accents, bold UI headings, or CSS-transitioned wheel scroll — push back. Those break the system. Suggest a-record (warm/cream) or linear (gray/blue) instead.

17 · For AI · Tailwind preset

把 tailwind-tokens.js 作为 preset 引入，立刻获得 bg-void、text-ember、rounded-shell、shadow-depth。
// tailwind.config.js
module.exports = {
  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

// then in your markup:
<body class="bg-void text-ink min-h-screen">
  <article class="bg-depth rounded-shell shadow-depth p-7">
    <h1 class="text-hero font-display tracking-tight">Footage,</h1>
  </article>
</body>
