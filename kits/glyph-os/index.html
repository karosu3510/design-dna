Glyph OS

像素桌面 OS。纯黑画布，VT323 数字，唯一红点表示 live，唯一柠檬绿表示充电。每一个模块都像桌面上的一台独立设备。Token 一旦放进任何场景里——长文阅读、设置面板、changelog——仍然是同一个 OS。

04动效

Glyph OS 的动效是数字而非模拟。像素帧切换用 step easing，实时数字用 setInterval 心跳，绝不用 CSS transition。

/* 帧切换：像素帧不能 tween */
--gl-ease-step: steps(1, end);

/* 罕见的平滑过渡 */
--gl-ease-out:  cubic-bezier(0.22, 0.61, 0.36, 1);
--gl-dur-tick: 60ms;
--gl-dur-base: 240ms;

/* 数字必须用 setInterval 心跳，不要写 CSS transition */
setInterval(() => {
  cpuNum.textContent = Math.round(load * 100);
}, 700);

15AI 接入 · Cursor / Claude 提示词

把下面这段贴进 .cursorrules 或任何 LLM 系统提示词，AI 生成的 UI 立刻进入 Glyph OS 风格。

↗ ai-prompt.md 
Use the Glyph OS design system for all UI in this project.

- Page background pure #000000. Cards #141414. Secondary fills #1b1b1b.
- Surfaces separate via background step + 1px line, NEVER shadow.
- VT323 for all numbers/labels (tabular-nums). Inter only for short body copy on the inverse card.
- Two single-purpose accents: #ff3b30 (live/error), #c8ff5e (charging). Nothing else colored.
- Radius scale 22/18/10/8/999 only. 4px spacing grid.
- Digital motion: steps(1, end) for cell swaps; tick numbers via setInterval, never CSS transition.
- Reuse .gl-card / .gl-cap / .gl-pixel / .gl-display / .gl-rec / .gl-tape / .gl-row / .gl-bars before authoring new CSS.
- Inverse card .gl-card--inverse at most ONCE per layout.

If a request requires a third accent color, soft shadow, display serif, or warm/cream tones, push back — those break Glyph OS.

16AI 接入 · Tailwind 预设

把 tailwind-tokens.js 当 preset 引入，所有命名空间立即可用。

// tailwind.config.js
module.exports = {
  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

// markup:
<div class="bg-canvas text-ink min-h-screen font-pixel">
  <article class="bg-card border border-line rounded-card p-4">
    <div class="text-display-gl">16:48</div>
  </article>
</div>
