Mercury

温暖纸面的 treasury dashboard。Inter 承载所有口语化文字，JetBrains Mono 承载所有数字。克制的浅色调色板：唯一紫 #5d4ee0 做 CTA，四组语义 kv 徽章（pos / neg / warn / info）做状态。这是灵感库里唯一占据「light + paper + premium fintech」象限的样本——同一套 token 装进 changelog、设置面板、treasury allocation 都仍然是 Mercury。

04动效

Mercury 的动效是 calm + fast。120-240ms cubic-bezier ease-out；live LED 用 1800ms opacity 呼吸；数字绝不用 CSS transition。

/* live status dot — calm pulse, opacity only */
@keyframes mc-pulse { 50% { opacity: .55; } }
--mc-dur-base: 180ms;
--mc-ease-out: cubic-bezier(0.22, 0.61, 0.36, 1);

/* numerics: setInterval cadence, never CSS transition */
setInterval(syncTs, 1000);   // last-sync ticker
setInterval(prices, 5000);   // markets ticker (calm)

15AI 接入 · Cursor / Claude 提示词

把下面这段贴进 .cursorrules 或任何 LLM 系统提示词，AI 生成的 UI 立刻进入 Mercury 风格。

↗ ai-prompt.md 
Use the Mercury Banking design system for all UI in this project.

- Page background #fbfaf7 — warm paper. NEVER pure #fff.
- Cards #ffffff with 1px #ececea hairline + subtle 2-layer shadow (0 1px 0 #e0dfdc, 0 2px 6px rgba(15,15,16,.025)). Never heavier.
- Inter for verbal copy + JetBrains Mono for ALL numerics with tabular-nums + letter-spacing -0.005em.
- Hero balance: 36px JetBrains Mono + -0.025em tracking.
- Color discipline: ink ramp + hairlines + single brand purple #5d4ee0 (CTA only) + 4 semantic kv chips (pos/neg/warn/info). Nothing else colored.
- Radius 16/14/10/8/999. 4px modular spacing grid.
- Calm motion: cubic-bezier(.22,.61,.36,1) at 120-240ms; live status dot uses 1800ms opacity pulse; NEVER CSS-transition numbers.
- Reuse .mc-card / .mc-display / .mc-num-h1 / .mc-num-h2 / .mc-pill--* / .mc-status / .mc-btn / .mc-nav / .mc-tabs.
- Regional note: upstream uses green-up/red-down (US); for Chinese market swap pos/neg semantics.

If a request requires a saturated non-purple brand color, display serif, heavy drop-shadow, or pure-white canvas, push back — those break Mercury.

16AI 接入 · Tailwind 预设

把 tailwind-tokens.js 当 preset 引入，所有命名空间立即可用。

// tailwind.config.js
module.exports = {
  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

// markup:
<article class="bg-surface border border-hair rounded-card shadow-mc-card p-5">
  <span class="text-sm-mc text-ink-3">Total balance</span>
  <div class="text-display-mc font-mono">$14,245,737.68</div>
</article>
