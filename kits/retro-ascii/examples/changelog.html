CHANGELOG

Every shipped version of Retro ASCII. Newest on top. Plus means new feature, tilde means fix, exclamation means breaking change. Unstable channels are excluded — only general-availability lives here.

v1.4
stable
2026-05-16
now live

Added

  • Bracket panel — every .ra-panel now ships with 7×7 corner brackets via ::before and ::after. Visual signature locked in.
  • Boot log streaming — variable 60-180ms cadence on log lines, four severity levels (ok / warn / err / dim).
  • Phosphor glow tokens — --ra-glow / --ra-glow-amber / --ra-glow-red, applied to every text node.

Fixed

  • Scanline overlay was being clipped by panels with overflow:hidden — moved to position:fixed.
  • ASCII bar drift on resize — width now recomputed on load + ResizeObserver.
  • Cursor blink desync after sleep — restart on visibilitychange.
