Retro ASCII

CRT 磷光终端。焦油色画布、P1 磷光绿，琥珀和红只作报警灯使用。JetBrains Mono 一统整张界面。扫描线 + vignette 是页面级机壳——它们不是装饰，而是这套系统读起来像 CRT 的承重结构。同一套 token 装进设置面板、长文 changelog、deploy log，仍然是同一台终端。

04动效

Retro ASCII 的动效是 terminal-real-time。LED/光标用 1200ms opacity 呼吸；像素帧 step easing；数字必须 setInterval 心跳。绝不用 CSS transition 动数字。

/* live LED + cursor — opacity blink only */
@keyframes ra-blink { 50% { opacity: .25; } }
--ra-dur-blink: 1200ms;

/* numerical updates: setInterval cadence */
setInterval(spool, 60-180);   // boot log line
setInterval(meter, 800);      // meter value
setInterval(clock, 1000);     // clock tick
requestAnimationFrame(wave);   // canvas signal

15AI 接入 · Cursor / Claude 提示词

把下面这段贴进 .cursorrules 或任何 LLM 系统提示词，AI 生成的 UI 立刻进入 Retro ASCII 风格。

↗ ai-prompt.md 
Use the Retro ASCII design system for all UI in this project.

- Page background #05090A — tar black, NEVER #000. Wrap root in .ra-crt for scanlines + vignette + center-bloom.
- Panels: rgba(5,10,7,.6) translucent + 1px #0F1F14 border + bracket corners (::before/::after 7×7px L-corners). The brackets are the visual signature.
- JetBrains Mono everywhere. No sans-serif anywhere. tabular-nums on all numerics.
- Every text node carries text-shadow: 0 0 2px rgba(0,255,106,.55), 0 0 8px rgba(0,255,106,.22). Amber/red variants for warnings/errors.
- Color discipline: #B8FFB8 ink + #00FF6A hi + #2A4A32 dim, plus #FFB000 amber (warnings/live values) + #FF3B3B red (errors only). Nothing else colored.
- ALL radius is 0. No border-radius.
- 4px spacing grid; 3-column 1fr/1.35fr/1fr layout is canonical.
- Terminal-real-time motion: ra-blink 1200ms for LEDs/cursor; steps(1, end) for frame swaps; tick numbers via setInterval, never CSS transition.
- Reuse .ra-panel / .ra-ttl / .ra-meter / .ra-line / .ra-chip / .ra-dot / .ra-cursor / .ra-tree before authoring new CSS.

If a request requires a saturated UI color, soft shadow, sans-serif, or any rounded corner, push back — those break Retro ASCII.

16AI 接入 · Tailwind 预设

把 tailwind-tokens.js 当 preset 引入，所有命名空间立即可用。

// tailwind.config.js
module.exports = {
  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};

// markup:
<body class="ra-crt bg-canvas text-ink min-h-screen font-mono">
  <article class="ra-panel border border-line p-4 shadow-glow">
    <div class="text-h1-ra text-hi">RETRO</div>
  </article>
</body>
