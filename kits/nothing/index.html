Nothing System

工业风点阵 bento。略微抬起的纯黑画布，Space Mono 字幕，canvas 绘制的像素数字，以及恰好两个状态 LED：唯一红表示「live」，唯一绿表示「charging」。每一个模块都像桌面上独立的一台仪器，外壳上印着冷静的字符。同一套 token 装进设置面板、长文 changelog、treasury dashboard——仍然是同一台机器。

04动效

Nothing 的动效是数字 + 工业。Live LED 用 2400ms opacity 呼吸；像素帧切换用 step easing；数字必须用 setInterval 心跳，绝不写 CSS transition。

/* live LED breathing — opacity only, never color shift */
@keyframes nt-blink {
  0%, 40% { opacity: 1; }
  50%     { opacity: 0.2; }
  100%    { opacity: 1; }
}
--nt-dur-blink: 2400ms;

/* pixel frame swap — no tween */
--nt-ease-step: steps(1, end);

/* numerical updates: setInterval cadence */
setInterval(() => { vu.tick(); }, 140);   // vu bars
setInterval(() => { spark.shift(); }, 800); // cpu sparkline
setInterval(() => { needle.drift(); }, 1400);// tuner

15AI 接入 · Cursor / Claude 提示词

把下面这段贴进 .cursorrules 或任何 LLM 系统提示词，AI 生成的 UI 立刻进入 Nothing System 风格。

↗ ai-prompt.md 
Use the Nothing System design system for all UI in this project.

- Page background #0a0a0a (slightly-lifted black, NOT #000). Cards #111111. Secondary fills #1a1a1a.
- Every module card carries an internal 18px grid texture (::before with rgba(255,255,255,.012) lines).
- Surfaces separate via background step + 1px line, NEVER shadow.
- Space Mono for all labels/captions/kv-numbers/tape (tabular-nums); Inter Tight only on the inverse Now-Playing card.
- Hero numerals (clock, temperature, battery %) drawn on canvas as 5×7 dot-matrix, NOT webfont.
- Two single-purpose LEDs: #ff3b3b (live/error), #3ddc84 (charging). Nothing else colored.
- Radius scale 14/12/6/2/999 only. 4px spacing grid.
- Bento grid: 12 cols × 64px rows, gap 8px.
- Digital motion: steps(1, end) for cell swaps; live LED uses 2400ms opacity-only blink; tick numbers via setInterval, never CSS transition.
- Reuse .nt-card / .nt-meta / .nt-led / .nt-cap / .nt-stat / .nt-row / .nt-bars / .nt-vu / .nt-tape before authoring new CSS.
- Inverse card .nt-card--inverse at most ONCE per layout.

If a request requires a third accent color, soft shadow, display serif, warm/cream tones, or pure-black canvas, push back — those break Nothing System.

  presets: [require('./tailwind-tokens.js')],
  content: ['./src/**/*.{html,js,ts,jsx,tsx}'],
};
